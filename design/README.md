# Handoff: ATIS Analyzer — Tauri 데스크탑 앱

## Overview
김포국제공항(RKSS) ATIS 전문(電文)을 폴더 감시로 자동 수집·파싱하여 통계 분석, 지도 시각화, 원문 열람을 제공하는 데스크탑 앱 디자인. 대상 사용자는 KAC 보라매(항공 운영/관제 지원) 담당자. 목표 플랫폼: **Tauri** (Rust 백엔드 + 웹 프론트엔드).

## About the Design Files
이 번들의 파일들은 **HTML로 제작된 디자인 레퍼런스**입니다 — 의도된 룩과 동작을 보여주는 프로토타입이며, 그대로 배포할 프로덕션 코드가 아닙니다. 과제는 이 디자인을 **대상 코드베이스의 기존 환경(Tauri + React/Vue/Svelte 등)에서 그 프로젝트의 패턴과 라이브러리로 재구현**하는 것입니다. 아직 환경이 없다면 Tauri에 적합한 프론트엔드 프레임워크를 선택해 구현하세요.

- `ATIS Analyzer.dc.html` — 메인 디자인. `<x-dc>` 안의 마크업(인라인 스타일)과 하단 `<script type="text/x-dc">`의 `Component` 클래스(상태/파생값 로직)를 참조. `{{ path }}` 홀은 로직 클래스 `renderVals()`가 채우는 값.
- `map.html` — 지도 뷰에 iframe으로 삽입되는 Leaflet 지도 (독립 실행 가능, 그대로 열어볼 수 있음).
- `support.js` — 프로토타입 런타임. 참조용 아님, 무시.

## Fidelity
**High-fidelity.** 색·타이포·간격·인터랙션이 최종 의도값입니다. 픽셀 단위로 재현하되, 데이터 생성 로직(`recs()`의 시드 난수)은 목데이터이므로 실제 파서/DB로 대체합니다.

## App Frame
- 창: 1280×800 기준 디자인 (리사이즈 대응 필요), radius 12px는 OS 창 프레임에 위임
- 좌측 사이드바 208px 고정 + 우측 메인 영역 (flex)

## Interactions & Behavior
- 내비 클릭으로 뷰 전환 (stats/map/import), 상태 유지
- 기간 전환(24h/7d/30d) 시 전체 통계 재계산 — 24h: 48건×30분, 7d: 168건×1h, 30d: 240건×3h (실제 구현은 DB 쿼리)
- 히트맵 셀·갱신 빈도 막대·전환 이벤트 도트 클릭 → 해당 레코드 원문 모달
- hover: 카드 내 셀은 인셋 링, 버튼류는 `rgba(0,0,0,0.04)` 배경 또는 brightness 필터
- 토글/스위치 전환 150ms transition

## State Management
- `view` ('stats'|'map'|'import'), `range` ('24h'|'7d'|'30d'), `mapIdx` (스크러버 인덱스), `playing`, `windViz`, `rawIdx` (모달 열림 시 레코드 인덱스, null=닫힘)
- 파생값은 모두 레코드 배열에서 계산 (KPI, 차트 포인트, 바람 장미 섹터, 히트맵 등) — 로직은 dc.html 하단 `Component` 클래스의 `renderVals()` 참조
- 실데이터: Tauri 측에서 폴더 감시(notify crate) → 파싱 → 프론트로 이벤트 push
